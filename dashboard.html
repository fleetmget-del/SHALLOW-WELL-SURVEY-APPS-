Connect to the Google Sheet

  1. In the Google Sheet: Extensions → Apps Script, paste google-apps-script.gs, and set your own DASHBOARD_KEY.
  2. Deploy → New deployment → Web app (Execute as: Me · Who has access: Anyone).
  3. Paste the Web App URL (ends in /exec) and the key below.
The key keeps interviewee names private: phones can only send records, only this dashboard can read them.
